# Oppgaveliste – Rettført Flyter

## Kvitteringer
- [x] Etter «Kjøpet er registrert» / «Fakturaen er sendt»: knappene «Gå til oversikt» og «Nytt kjøp» / «Ny faktura»

## Lønn: tre faner (Lønnskjøring, Ansatte, Utlegg)
1. [x] Ansatte-fanen: «Legg til ansatt» og ett kort per ansatt (utbetalt hittil i år, skatt, feriepenger som «Sara får 18 420 kr i juni»). Excel-eksport til regnskapsføreren.
2. [x] Overtidsregler per ansatt eller for hele bedriften, skrevet som setninger med felt. Forslaget er lovens minimum (40 %).
   - Timer registreres som start og slutt, og Rettført deler dem opp i vanlig tid, 50 % og 100 %. Hver del blir en egen linje på lønnslippen.
   - Assistenten (Selskap) fyller inn fra fritekst og lager et forslag som må godkjennes.
   - Kontrollen varsler om dager over 13 timer og når årets overtid nærmer seg maks.
3. [x] «Legg til på lønnslippen» med søk (bonus, overtid, km-godtgjørelse). Vi velger lønnstypen, og én setning forklarer hva den betyr.
4. [x] Utlegg: den ansatte tar bilde av kvitteringen og du godkjenner. Beløpet kommer på neste lønn. I Gratis fyller den ansatte ut selv.
5. [x] Arbeidsgiveravgift og skattetrekk på Frister: «Du skal betale 12 340 kr innen 15. november», med knapp for betalingsfil.

## Droppes
Egen side for faste lønnslinjer, pensjon og lønnsinnstillinger. Pensjon legges inn i oppsettet og lønnskjøringen.
